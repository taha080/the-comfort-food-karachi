# The Comfort Food

Good Food. Familiar Feelings. — Karachi online ordering.

**Live site:** https://taha080.github.io/the-comfort-food-karachi/

## What it is

A food business website for a Karachi kitchen. Customers browse the menu and place a delivery order on the site.

- **Menu:** Pasta, Noodles, Dumplings, Sandwiches & Wraps
- **Ordering:** order form on the site with phone / WhatsApp number
- **Delivery:** Karachi-wide Cash on Delivery

## Run locally

This is a static site. Open `index.html` in a browser — no build step, no server needed.

## Files

- `index.html` — the whole site (menu, ordering form, delivery info)
- `assets/` — images and other static assets
